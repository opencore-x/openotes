# Contributing

Thanks for taking the time to contribute! Here's how to get started.

## Getting started

1. Fork the repo and clone your fork:
   ```bash
   git clone https://github.com/<your-username>/openotes.git
   cd openotes
   ```
2. Create a branch for your work:
   ```bash
   git checkout -b my-feature
   ```

## Making changes

- Keep changes focused and commit with clear messages.
- Test your changes before pushing.

## Opening a pull request

1. Push your branch:
   ```bash
   git push origin my-feature
   ```
2. Open a PR against `main` and describe what you changed and why.
3. A maintainer will review it — thanks for helping out! 🎉
